## 维护要求

1. 不把生成插画改写为“现场照片”“实景”或“探店照片”。
2. 如果插画中的建筑或食物容易被误认为准确复原，必须在页面说明其为概括性主题画面。
3. 生成文件需要与其他正式图片一样提供 720、1440 两档 WebP/AVIF，并通过构建期文件校验。
4. 后续若替换为授权实拍，需要同步更新 Frontmatter、图片署名、许可、本页记录和内容审计。
