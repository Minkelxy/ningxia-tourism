| 目标 | 说明 | 依赖 |

### 阶段三：性能与体验（优先级：中低）

| 目标 | 说明 | 当前指标 |
|------|------|----------|
| Lighthouse 性能提升 | 移动端 performance ≥ 0.95（当前门禁 0.9） | 4 个 URL 审计 |
| 图片懒加载 | 视口外图片使用 loading="lazy"，减少首屏请求 | ResponsiveImage 当前无 lazy |
| 手记正文代码高亮 | react-markdown 暂不支持代码块高亮 | 可引入 rehype-highlight |
| 地图边界简化 | 移动端加载简化版 GeoJSON，减少首屏解析 | 当前全量加载 |
| PWA 离线支持 | Service Worker 缓存静态资源与数据 | 无 SW |

### 阶段四：工程化（优先级：低）

| 目标 | 说明 | 当前状态 |
|------|------|----------|
| CI 缓存优化 | GitHub Actions 缓存 node_modules 与 Vite 构建产物 | 当前每次全量安装 |
| 依赖版本升级 | React 19 / Vite 7 评估 | 当前 React 18 / Vite 6 |
| 视觉回归测试 | 引入 Playwright 截图对比，防止 UI 意外变更 | 仅功能 E2E |

## 技术债务清单

| 编号 | 描述 | 影响 | 处理方式 |
|------|------|------|----------|
| TD-01 | TransportLayer / GovernmentLayer 无 onKeyDown | 纯展示图层键盘焦点无反馈 | 可加 tooltip 弹窗或移除 tabIndex |
| TD-02 | process-images.ts 无批量模式 | 图片处理效率低 | 补 glob 批量入口 |
| TD-03 | E2E 测试依赖 Playwright 浏览器下载 | CI 环境可能受限 | 已有回退策略（browser 子代理） |
| TD-04 | .trae/ 仍保留在本地工作区 | 不影响 git，但占磁盘 | 属 IDE 行为，无需处理 |
